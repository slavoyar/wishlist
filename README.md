# Wishlist

Personal wishlist at [wishlist.slavoyar.tech](https://wishlist.slavoyar.tech).

## Local development

```bash
npm install
cp .env.example .env.local
npm run db:seed
npm run dev
```

## Stack

- Next.js 15 (App Router)
- SQLite + Drizzle ORM
- Tailwind + shadcn-style primitives
- Docker / GHCR deploy (same pattern as portfolio)
